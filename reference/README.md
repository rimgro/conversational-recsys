# Эталон: бейзлайн team1

`team1/` — ноутбуки и маленькие артефакты из ветки `team_1_baseline` (коммит 3bd3d49): политика отбора, порядок
признаков, метрики, анализ вклада кандгенов. Индексы, кэш кандидатов, модель и сабмит остались в той ветке
(`git show origin/team_1_baseline:<путь>`).

Бейзлайн перенесён в пакет `recsys/` и сверен с этими файлами:

| что | team1 | `python -m recsys` |
|---|---|---|
| части запросов (index / ranker_train / valid / test) | 259 505 / 30 000 / 4 000 / 10 000 | то же |
| списки 11 кандгенов на valid | — | совпадают (у `audio_*` — с точностью до порядка равных скоров) |
| union recall / recall@150 на valid | 0.9515 / 0.7085 | 0.9515 / 0.7085 |
| обучающие группы / строки ранкера | 20 688 / 3 102 287 | то же |
| их модель на наших признаках, nDCG@20 valid | 0.419214 | 0.419199 |

Ноутбуки здесь только для справки: пути в них рассчитаны на структуру их ветки.

**Важно:** team1 использует `query_type` (политика отбора по типу и признак ранкера), а его использовать нельзя.
Сверка выше сделана с ним; в `recsys/` его нет — отбор одинаков для всех запросов, признака типа нет.
