# Semantic ID треков (RQ-VAE по MuQ)

Коды треков для двухбашенного кандгена: каждый трек — 4 числа, на входе модели — 4 токена.
Код — `recsys/semantic_ids.py`, проверка — `python check_semantic_ids.py`.

## Файлы

Папка `semantic_ids.dir` в `configs/default.yaml` (по умолчанию `artifacts/semantic_ids/`, в git не хранится).
Получены в DataSphere (`/home/jupyter/tiger/tiger_larger_outputs/`).

| файл | что |
|---|---|
| `semantic_codes.npy` | `int64`, `(64016, 4)`. Строка `i` — `i`-й трек `tracks_meta` по возрастанию `m4a_id` |
| `rqvae_checkpoint.pt` | `{'state_dict', 'config', 'input_dim': 128}` — RQ-VAE, который построил коды |

Колонки кодов:

| позиция | значения | что |
|---|---|---|
| 0, 1, 2 | 0..255 | коды RQ-VAE, уровни 1–3 |
| 3 | 0..8 | номер трека среди треков с теми же тремя кодами (почти всегда 0) |

## RQ-VAE

Вход — MuQ-эмбеддинг трека (128 чисел, `muq_embedding` в `tracks_meta`): коды описывают **звучание**,
не текст, не теги и не прослушивания.

```
энкодер:  MuQ 128 -> Linear 128 -> ReLU -> Linear 32 -> ReLU -> Linear 32 (без bias)  = z
квантование: 3 уровня, кодбук 256 x 32; код уровня k — ближайший (евклидово) центроид к остатку,
             остаток -= центроид
декодер:  32 -> 32 -> ReLU -> 128 -> ReLU -> 128
```

Вектор трека из кодов — сумма трёх центроидов (`SemanticIDs.quantized()`, 32 числа): приближение `z`,
ошибка в среднем 22% нормы `z`. Центроиды по отдельности — `SemanticIDs.centroids()`, `(n, 3, 32)`.

## Что проверено (`check_semantic_ids.py`)

- Чекпоинт по MuQ из `tracks_meta` воспроизводит **100%** кодов: порядок строк — `tracks_meta` по `m4a_id`,
  отдельный `items.parquet` не нужен.
- Все 256 значений каждого уровня используются, треки распределены ровно (медиана ~245 на значение).
- Коллизии: первые три кода общие с другим треком у **7.8%** треков (4 988); с четвёртой позицией — ни одного.
  Больше половины из них (2 785) — другая запись той же песни, у неё тот же звук.
- Дубли песен: у **9.2%** треков есть другая запись той же песни (один ISRC или одинаковые
  «артист + название» без «(Live)», «- Remastered»). Для полного softmax такой трек — негатив,
  который на деле та же песня: маскировать (`--out` сохраняет группы в `duplicates.csv`).

## Использование

```python
from recsys.semantic_ids import load_semantic_ids
sid = load_semantic_ids(cfg)                 # коды + кодбуки (чекпоинт грузится через torch)
sid.codes                                    # (64016, 4)
sid.vocab_sizes                              # [256, 256, 256, 9] — размеры таблиц эмбеддингов
sid.aligned(catalog.track_ids)               # коды в порядке каталога
sid.quantized()                              # (64016, 32): сумма центроидов
```
