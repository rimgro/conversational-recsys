# Разговорная рекомендация музыки

По текстовому запросу на русском, истории прослушиваний и профилю пользователя найти трек в каталоге
из 64k треков. Данные: **Music4All-CRS** (Music4All-Onion + синтетические запросы, 11 типов: название,
строчка текста, жанр, настроение, эпоха и др.).

> Код сейчас в ветке [`dev/base-structure`](../../tree/dev/base-structure). Подробное описание — в её README,
> описание датасета — в `docs/dataset.md`.

## Пайплайн

1. **Разбор запроса** → структурированное саммари (теги, исключения, страна, эпоха): словарь для русского или LLM.
2. **Кандидаты**: BM25 по тегам, своя история пользователя, поиск по названию (с транслитом), аудио-эмбеддинги MuQ, популярное.
3. **Слияние** списков (RRF) и фильтры.
4. **Ранкер** — пока заглушка (порядок RRF), есть эвристический бейзлайн и клиент для ранкера по API.
5. **Ответ** пользователю — пока шаблон, LLM по флагу.

## Запуск

```bash
pip install -r requirements.txt
pytest -q
jupyter lab main.ipynb    # или открыть в DataSphere из корня репозитория
```

Без данных всё работает на синтетике. Для настоящих данных: положить `tracks_meta.parquet`, `train.parquet`,
`test_public.parquet` в `data/` и поставить `data.source: crs` в `configs/default.yaml`.
